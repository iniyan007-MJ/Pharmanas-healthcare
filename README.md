- **Pharmaceutical Products** (`/products/pharmaceuticals`)
- **Medical Devices** (`/products/medical-devices`)

- **Interactive WhatsApp Product Enquiry & Quotation Calculator**

## 🚀 Setup & Running Instructions

### 1. Navigate to the Project Directory
```bash
cd C:\Users\iniya\.gemini\antigravity\scratch\duonovik-healthcare
```

### 2. Install Dependencies (if needed)
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Production Build & Verification
```bash
npm run build
npm run start
```
